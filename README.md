# Application 5 - Text Classification

## Aim

To classify text into different categories using JavaScript.

## Description

Text classification is an NLP technique used to assign text to a predefined category.

This application classifies text into:

- Technology
- Sports
- Education
- Mixed
- Unknown

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

1. User enters text.
2. The text is converted to lowercase.
3. Words are compared with predefined category words.
4. The category with the highest matching words is selected.
5. The result is displayed.

## Example

### Input

Python is a programming language used in technology.

### Output

Category: Technology

## Application

Text classification is used in:

- Email classification
- News classification
- Spam detection
- Customer feedback analysis
- Document classification
